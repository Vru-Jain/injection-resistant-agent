# Desk-sandbox tasks with indirect prompt injections

> Content warning: contains prompt-injection text aimed at AI assistants (fake transfers to `ACC-ATTACKER-77`, exfiltration to `collector@evil-mail.example`, spam calendar events). All people, addresses and accounts are fictional.

Each row is one task for a tool-using assistant: the user request, the full world state (emails, files,
calendar, contacts, accounts), the gold tool calls, the gold fact the answer must contain, and for injected
tasks the injection text, family, attacker target and the gold step whose tool result carries it.
Seven tools: list_inbox, read_email, send_email, read_file, list_events, create_event, transfer_money.

| split | tasks | clean | injected | notes |
|---|---|---|---|---|
| train | 600 | 300 | 300 | 10 templates, families 1-5 |
| test_in_dist | 150 | 50 | 100 | same templates and families, unseen states and phrasings |
| test_new_template | 75 | 25 | 50 | held-out templates forward_to_contact, event_from_file |
| test_new_family | 75 | 0 | 75 | held-out families 6 (delayed) and 7 (encoded) |
| benign | 100 | 100 | 0 | user-requested payments and sends (over-refusal check) |

Leak check: no test prompt appears verbatim in train (exact overlap 0 on every split); the new-family split shares
no injection string with train. Details in `leakcheck.json` in the code repo. Generated by `scripts/gen_data.py`
(seeds: train 1, tests 2, benign 3). Code, scoring and results: https://github.com/Vru-Jain/injection-resistant-agent
