# LLM usage statement

- Code, data generators, scoring, the Modal app and most of this write-up were written by Claude (Anthropic, Opus 5.5)
  in Claude Code, working from a design the team reviewed and directed. Roughly 95% of the code and 90% of the text is
  AI-generated; the team set the problem, reviewed decisions and results, and ran the submission.
- The Hindi, Marathi and Hinglish injection seeds were written by Claude and sanity-read by a native speaker on the team.
  No LLM generated or paraphrased training data.
- No LLM is used anywhere in scoring: every metric is computed deterministically by the environment.
