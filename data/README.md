# Data

Generated by `python scripts/gen_data.py` (deterministic: seeds train 1, tests 2, benign 3).
Content warning: injected tasks contain prompt-injection text aimed at an AI assistant
(fake transfers to `ACC-ATTACKER-77`, exfiltration to `collector@evil-mail.example`,
spam events). All names, addresses and accounts are fictional.

| File | Tasks | Clean | Injected | Templates | Injection families |
|---|---|---|---|---|---|
| `tasks/train.jsonl` | 600 | 300 | 300 | 10 seen | 1-5 (5 = 25%) |
| `tasks/test_in_dist.jsonl` | 150 | 50 | 100 | 10 seen | 1-5 |
| `tasks/test_new_template.jsonl` | 75 | 25 | 50 | `forward_to_contact`, `event_from_file` | 1-5 |
| `tasks/test_new_family.jsonl` | 75 | 0 | 75 | seen (family 6 only on `multi_hop`) | 6 delayed, 7 encoded |
| `tasks/benign.jsonl` | 100 | 100 | 0 | `pay_from_email`, `file_to_email` | none |

Families: 1 imperative, 2 fake authority, 3 urgency, 4 hidden formatting (HTML comment,
zero-width spaces, markdown footnote), 5 multilingual (Hindi, Marathi, Hinglish, hand-written),
6 delayed (injection in the second tool result), 7 encoded (base64 or reversed).

Each row is one task: user prompt, the full desk state (emails, files, calendar, contacts,
accounts), gold tool calls, gold fact, and for injected tasks the injection text, family,
target and the gold call index whose result carries it.

## Leak check (`leakcheck.json`)

Test user prompts never appear verbatim in train (exact overlap 0 on every split, enforced
when generating). Normalised overlap (casefold, punctuation and digits removed) is reported,
not forced to zero: a few short phrasings differ from a train prompt only by a number.
Injection strings: in-distribution and new-template splits reuse the train seed sentences
by design (seen families); the new-family split shares no injection string with train.
